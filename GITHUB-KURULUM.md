# GitHub geliştirme dalı

Güncel uygulama dalı `p1/unified-life-engine`. Uygulama kodu ve yapay test verileri bu dalda geliştirilir. Kaynak paketleri ve yedekler uygulamaya cihazdan alınır. Bu dosyaları depo klasörünün dışında sakla.

Dalın eski sürümlerinde gömülü kataloglar ve okuyucu içeriği vardır. Yeni commit eklemek geçmiş commit'leri, diğer dalları, çatalları veya daha önce indirilmiş kopyaları kaldırmaz.
